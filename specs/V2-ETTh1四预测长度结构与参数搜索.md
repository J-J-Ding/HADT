# V2 — ETTh1四预测长度结构与参数搜索

用户已授权修改模型、参数并使用四张GPU，随后明确要求覆盖H=96/192/336/720，且对比实验使用相同历史窗口。本规范记录本轮已授权的有限搜索方案，不需要另行确认。

- 保留旧HADT及历史结果，新模型入口为`models/hadt_detail.py`，专用层为`layers/hadt_nq/local_detail.py`。
- 数据：ETTh1，原60/20/20时间划分，训练前缀scaler，不使用测试指标选模型。
- 历史长度预实验：96/336/512，同一reference结构、同一seed2024、四个预测长度，各最多6轮。等权汇总四个长度的验证指标，固定一个历史长度。
- 结构参数筛选：固定所选历史长度，18个预先列举的候选×四个预测长度，seed2024，各最多6轮。候选及完整参数以`experiments/detail_search.py`为准，在启动前写入协议和哈希。
- 候选覆盖：MLP宽度32/64/96、层数1/2/3、dropout与weight decay、学习率1e-4/3e-4/1e-3、小patch、局部/空洞depthwise卷积、更多采样点、近期加密网格、线性/24小时季节中位数残差支路，以及训练期一阶差分辅助项。
- 可变形注意力和有序分位数头保留。中位数残差对全部分位数加同一偏移，保持顺序。旧模型默认计算不变。
- 三种子确认：筛选排名前三，加reference强制保留，种子2024/2025/2026，四个预测长度，各最多30轮，早停patience7，全部统一历史长度。筛选不是充分收敛证据，可能漏掉慢收敛候选；报告明确其局限。
- 主验证指标为proper pinball。辅助指标为中位数一阶差分MAE、大变化时刻MAE、PICP90、PINAW90及预测/真实总变差比。大变化阈值为各变量训练前缀绝对一阶差分的95%分位数；不使用验证或测试拟合阈值。
- 搜索分数：四个预测长度各自相对reference归一化，再等权平均，`0.7*pinball_ratio + 0.2*delta_mae_ratio + 0.1*jump_mae_ratio`。先比较历史长度，再固定窗口比较结构，不能混合不同历史长度作最终模型排名。
- 同时冻结两个配置：纯平均验证pinball最优；细节平衡最优（平均pinball不超过最优的1.02倍，各H覆盖率不低于reference超过2个百分点，再按上述综合分数）。若无非reference候选满足条件，诚实保留reference或精度最优并标明约束未满足，不强求改进。
- 最后仅评估reference及冻结的精度/细节配置（三者若重复则去重）的测试集，分别保存四H×三种子的最佳权重、指标与固定首/中/末窗口曲线。最终推荐配置在四H间保持同一历史长度和结构超参数，只调整输出H。
- 保留负结果，不能因测试效果不好追加测试驱动的调参；本轮只是所列有限空间和预算内的最优，不是全局最优证明，也不能保证消除过拟合或恢复不可预测噪声。
- 已多次研究过本数据集，独立测试的解释需保守；搜索与确认使用验证集会引入选择乐观性，三种子不是统计显著性保证。

## 确认阶段补充：按预测长度的部署选择

用户只要求各实验历史长度相同，没有要求不同预测长度必须用同一结构。确认阶段已观察到短/长预测的验证偏好不同，因此在任何测试之前补充：除原定全局精度/细节配置之外，按每个H的三种子验证均值，使用同样的精度和细节约束各冻结一个配置，写入独立`horizon_selection.json`。原`selection.json`和全局规则不修改；历史长度始终相同。

该补充在确认过程中提出，不宣称在初次训练前就已预声明。最终测试候选是reference、全局配置及这些按H验证选择配置的去重并集；每个入选结构仍完整测试四个H，避免只展示有利长度。另导出四份按H配置，但不把它们的拼接结果伪称为同一结构的成绩。
