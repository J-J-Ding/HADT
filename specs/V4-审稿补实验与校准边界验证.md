S1和S2采用单因素对照，而非完整K×a笛卡尔积。K会改变偏移投影的输出尺寸及参数量，需要随表报告参数量，不能声称完全等容量。

### S3：预先指定的边界对照

原网格为 r_k=(k-1)(N-1)/(K-1)，覆盖[0,N-1]；N=41时为[0,40]。

新对照只将参考点改为 r'_k=0.5+(k-1)(N-2)/(K-1)，即[0.5,N-1.5]，N=41时为[0.5,39.5]。继续使用p=clip(r'+a*tanh(offset),0,N-1)，其余参数、损失和训练规则不变。

该对照用于检查包含端点的均匀网格与边界插值退化是否影响结果，不预设内移网格更好。保留原均匀网格、零偏移初始化的真实行为，不能把观察到的梯度退化未经验证地重新包装为设计优势。

运行前进行小规模梯度检查：原网格右端零偏移处的插值梯度、内移网格的插值梯度、边界内外位置与输出形状均需符合实现。该检查不是训练效果证据。

## 4. 校准损失及验证选择

增加一个明确标注为探索性对照的平滑分位数校准正则项，保留原有非交叉输出头：

    c_hat[c,q] = mean_{b,h} sigmoid((Q_hat[b,h,c,q] - Y[b,h,c]) / T)
    L_cal = mean_{c,q} (c_hat[c,q] - tau[q])^2
    L_total = L_pinball + lambda * L_cal

- T固定为0.1，单位为各变量训练标准化后的目标单位，不再额外搜索温度。
- 逐变量计算覆盖再平均，避免不同变量的正负偏差先混合后抵消。
- 该正则项控制的是有限批次的边际分位数覆盖，不提供条件或同时覆盖保证，也不保证硬阈值测试覆盖必然改善。
- 正间隔头保持不变，校准项不通过排序、裁剪或测试后处理改变输出。

### 权重预实验：3组，只有验证，不读取测试指标

固定ETTh1/H96/seed2024，在lambda∈{0.1,1,10}上各训练最多8轮，早停与验证pinball选checkpoint规则保持不变。记录训练pinball、校准项、总目标，验证pinball和硬阈值分位数校准误差。

验证校准误差定义为逐变量、逐分位数的平均绝对偏差：

    ACE = mean_{c,q} abs(mean_{validation windows,h} 1[Y <= Q_hat_q] - tau[q])

这些窗口重叠，ACE仅作为描述性指标和验证选择依据，不将其数量当作独立样本数。

权重选择规则在运行前固定：

1. 优先保留验证pinball不超过既有无校准模型同一H/seed验证pinball的1.02倍的候选。
2. 合格候选中选择验证ACE最低者；再以验证pinball较低、lambda较小依次打破并列。
3. 如全部不合格，选择验证ACE最低者作为明确标注的取舍诊断，记录约束未满足；不因此声称获得更好的模型。
4. 将唯一权重冻结到H96、H720和全部3个种子。重新从头训练6组正式模型，不复用8轮pilot作为正式结果，也不按H重新选权重。

原模型获得了更多结构搜索，校准变体则获得额外权重搜索，需披露搜索预算。8轮筛查不能证明收敛；没有明显改善也应如实报告。

## 5. 统一指标和可视化

所有正式实验：完整测试pinball、CrossingRate、PICP50/80/90、PINAW90、NormalizedWinkler90、分位数ACE，以及既有delta_MAE、事件MAE。报告三种子的均值和样本标准差；记录最佳epoch、实际轮数和参数量。

必须同时解读覆盖、宽度和区间分数，不能仅因PICP变大而认定改善。ACE使用逐变量硬阈值覆盖，平滑训练正则的值不能代替测试ACE。

S1/S2/S3行为诊断使用相同的首/中/末三个测试窗口、全部7变量、全部预测步及全部种子：

- 边界命中率：位置距0或N-1不超过1e-6的比例。
- 采样点覆盖：每个head/step的不同floor(p)数量，再汇总；该指标表示不同插值邻域数。
- 偏移绝对值及其分布；按头汇总的归一化注意力熵，分母为log(K)。
- 原网格右端参考点的偏移和注意力质量；不得用单头、单案例代替总体结论。

## 6. 实现与运行顺序

当前主对比驱动会校验models/layers/utils/engine/data_provider/experiments及配置指纹。新增文件也可能改变source_manifest，因此这些目录及冻结配置在主实验结束前保持不变。

新增实验控制、正则项和内移网格子类暂放在独立scripts/reviewer_*脚本中。复用build_model、Trainer的train_objective接口及评估器；内移网格只覆盖解码器的参考位置输入，保持其余注意力计算一致。指标扩展与日志在独立脚本实现。若确需修改核心代码，使用隔离副本或等主协议结束后建立新的源码版本，不能更新旧协议指纹来掩盖模型改变。

运行步骤：

1. 保持当前四卡队列继续完成剩余主对比；Weather等大数据集仍最多10轮。
2. 在CPU上完成新增目标的有限梯度、形状、有序性检查，以及lambda=0等价原目标的检查。
3. 主对比结束后，补充实验使用四卡动态领取任务，每卡同一时刻一个本项目训练，不强制终止当前任务，也不修改他人的GPU进程。
4. 先派发3个校准pilot，同时其余空闲卡开始30个独立采样/边界正式任务。
5. pilot选择文件冻结后，6个校准正式任务进入队列。预实验失败不阻塞其他独立任务，但校准正式训练不得绕过选参门槛。
6. 每组测试完成且验证通过后写complete.json；无完成标记的任务不计为已完成。
7. 汇总36组正式结果、12组复用对照、3个pilot及主对比矩阵，核验checkpoint/config/metrics哈希及最佳验证epoch。先生成结果包与审稿回复依据，再更新正文数据。

新结果独立放在outputs/reviewer_revision_20261128/，包含protocol.json、jobs.json、selection.json、workers/、progress.json和各run目录。该目录不与已发表快照或原主对比完成标记混用。

当前计划不包含实测显存、延迟或额外第二数据集消融；如论文继续只主张参数量与精度的取舍，这些不是本轮必须项。也不根据测试结果决定是否继续追加候选。
