## 一、统一论文对象

建议正文采用 `configs/optimized_etth1.yaml` 的统一 `linear_skip` 结构：L336、patch16/stride8、D64、两层token-wise MLP、8头×8采样点的预测步条件化可变形解码器、有序分位数头、历史线性修正支路。

MLP块只混合每个patch内部的特征维，不混合patch位置；跨patch信息来自历史摘要、解码器检索及直接历史修正。变量独立计算并共享参数，不画跨变量注意力。差分辅助损失权重为0，不画成最终模型组件。历史修正对所有分位数加同一平移量，不改变其间距。

720步的 `local_fine` 是另一结构，可作为敏感性分析，不将各H的验证优选拼成单一模型主表。旧论文中的Transformer-3/D128以及上轮MLP-3/D64均为历史版本，不能让旧版消融充当新版结构的贡献证明。

## 三、优先补充的实验

### P0：最终模型与外部baseline的主表

最小完整方案：ETTh1、ETTh2 × H96/192/336/720 × HADT-NQ及四个外部baseline × seeds2024/2025/2026，共120组模型训练。满足完全相同数据和训练协议的已完成组可复用；其余重新训练。若保留高维泛化主张，再增加Traffic，对应60组。

- 冻结统一HADT结构后迁移到ETTh2/Traffic；如果各数据集另行调参，需给每个baseline相同的验证搜索预算，并明确这属于数据集内调参比较。
- 所有方法统一L336、数据文件、时间划分、scaler、预测H、分位数集合、验证选模规则与种子。每个H独立训练。
- 外部模型标为 DLinear-NQ、PatchTST-NQ、TimeMixer-NQ、iTransformer-NQ：官方点预测主干的本文分位数适配。不能把其结果称为原论文的概率预测结果。
- 当前实现是在标量点预测后接有序头；相同的是输出头的参数化形式，并非所有模型头部输入维度和模型容量相同。披露适配路径，保留point模式的训练检查，避免因适配欠佳夸大HADT优势。
- 基于验证集给baseline适度调学习率与正则化；对于最佳轮次位于epoch上限的模型，检查是否需要延长预算。不能仅用“相同30轮”认定全部收敛。
- 表中报告pinball、90%覆盖率、PINAW90、Normalized Winkler90；补充中位数MAE、一阶差分MAE、事件MAE。覆盖率以接近名义水平为目标，宽度必须结合覆盖率解读。
- 均值±样本标准差来自三个训练种子，不把密集滑动窗口视为独立重复试验；若增加统计推断，应考虑窗口重叠的时间依赖。
- 当前ETT采用60/20/20比例划分，必须写明。若改为常见固定月份协议，所有模型、消融和配置选择需在新协议下重新完成，不能混表。

### P0：最终结构上的机制消融

建议先做ETTh1的H96和H720，每组3种子，保持L336和其余超参数一致；除诊断性干预外，每个变体从头训练。完整模型可复用当前6组结果。

| 变体 | 只改变的机制 | 回答的问题 |
|---|---|---|
| Full | 完整linear_skip | 统一参考 |
| Fixed offsets | 将偏移固定为0，保留查询和采样注意力 | 学习采样位置是否有贡献？ |
| Shared horizon query | 所有h共享同一个可学习预测步嵌入，保留历史上下文 | 显式预测步身份是否必要？ |
| Dense decoder | 用全部历史patch的稠密交叉注意力替换采样，保留其余解码路径和修正支路 | 稀疏检索相对稠密检索的取舍是什么？ |
| No history correction | 去除线性修正，其余设置不变 | 局部变化改善是否主要来自修正支路？ |
| Fixed + no correction | 同时固定偏移并去掉修正 | 可变形机制的收益是否依赖修正支路？ |
| Independent head | 换为7个独立输出，训练仍用pinball | 有序头是否防止交叉，代价是什么？ |

上述6个额外变体共36组新训练。Full/Fixed/No correction/Fixed+No correction形成2×2比较，可分辨偏移学习与修正支路的独立作用及相互影响。优先看pinball和变化误差，不以可视化中的“曲线更抖”作为成功标准。

共享查询变体中，直接修正支路仍然随H变化；不能说整个模型的预测变成常数。Independent head报告交叉率和pinball；若区间端点发生反转，不能直接当作有效区间计算区间评分。可另外报告明确标注的排序后诊断，但不要替代原始交叉结果。

若资源允许，追加无编码器、同宽同深Transformer、patch-direct解码、无RevIN。MLP与Transformer比较应固定D、层数、学习率、正则化等，避免把整套配置搜索称为“单独替换编码器”的消融。

### P1：K、偏移边界与效率

- 最终结构在ETTh1/H96和H720比较K∈{4,8,12}，偏移上限a∈{0,0.5,1.5,3}；可先单种子验证筛查，再对预先指定的小组进行三种子报告。不要把历史旧模型的敏感性直接归于新模型。
- 重点记录零偏移对照、参考网格端点的边界命中率、有效不同采样点数、各头注意力熵、最近参考点的权重。这些是行为诊断，不单独证明机制有效。
- 如声称效率优势，固定同一GPU、batch、精度、H、通道数和实现设置，预热并同步后重复测推理延迟及峰值显存，同时给出参数量；共享GPU环境的训练耗时不能作为严谨加速结论。
- 不需要为了保留论文标题而保证可变形注意力总能获胜。若最终受控消融中偏移收益很弱，收缩创新主张或重新设计机制，再用新实验验证。

### P1：校准研究（按论文主张决定）

如果论文只主张有序分位数，完整披露校准误差即可，不必额外引入未验证的校准损失。如果主张可靠覆盖率，可追加有序性保持的后处理区间扩张：在验证集内预先划分独立校准段，确定非负扩张量，最终测试只评估冻结参数；对所有比较模型使用相同政策，同时报告原始/校准后的覆盖、宽度和区间评分。不要在时序相关数据上无条件宣称满足可交换性假设下的覆盖保证。
