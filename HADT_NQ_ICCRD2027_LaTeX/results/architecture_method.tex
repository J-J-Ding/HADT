\paragraph{Validation-selected working configuration.} The separate search in Section~\ref{sec:architecture-search} freezes MLP-3, D64, lr 3e-4 as the working variant. It uses $D=64$ and three pre-normalized residual per-token FFNs with hidden width 128, GELU, dropout 0.1, and final layer normalization. Each block uses affine maps and computes \begin{equation}\begin{aligned}A&=\operatorname{Drop}(\operatorname{GELU}(W_1\operatorname{LN}(Z))),\\Z'&=Z+\operatorname{Drop}(W_2 A).\end{aligned}\end{equation} These FFNs do not mix patch positions; temporal retrieval occurs in the horizon-conditioned deformable decoder. Patch length, stride, eight decoder heads, $K=8$, offset bound, RevIN and the ordered head are retained. The reference Transformer remains the comparator in historical tables. Width and learning rate were selected jointly with encoder type, so this configuration comparison does not isolate an MLP-only causal effect.
